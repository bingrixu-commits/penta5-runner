## 2. 五条规则落地映射

| 规则 | prompt v2 | 后端硬校验（拒收→重试，3 次失败不发布） |
| --- | --- | --- |
| 1 禁止惯性复制上期方案 | 组合与上期完全相同直接拒收 | `a/b` 集合与上期完全相同 → `禁止惯性复制上期方案` |
| 2 顺局风控 | 预警=是时打乱分布 + 轮换全部 B 子策略 | runaway=true 时，保留的每个 B 号位子策略必须与上期不同 |
| 3 分散原则 | 四号位策略错落，B 多号位子策略不得重复 | B 占 ≥2 号位时 `b_sub` 重复 → 拒收 |
| 4 冷反弹降 A 提 B | 冷反弹活跃时 A 取上限内最小值 1 个 | A 组下限 1（禁止 A=0）；上限沿用 `a_cap`（冷反弹活跃=1） |
| 5 候选池纪律 | 池内无合适标的理由标注「候选不足」，不得自选 | 杀码不在 pool 内 → 拒收（v1 已有） |

## 3. 强制自检清单（不可跳过）

模型必须输出
`self_check = {allocation_rederived, runaway_shuffled, dispersed, cold_rebound_adjusted, pool_confirmed}`，
缺项或任一项非 `true` → 后端直接拒收；与后端硬校验双层把关，封存新增 `self_check`、`policy` 字段留痕。

## 4. 顺局语义修正

按用户原文，`runaway_warning` 改为「同一套 A/B 分配**连续整组命中** ≥14 期」才触发；
出现未命中或换分配即清零重计（v1 原实现只数“同分配”，未要求命中）。
断言：14 期同分配全中 → true；任一未命中 → false；中途换分配 → false。
