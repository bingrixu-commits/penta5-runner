使用方法：
1. 保持两个文件在同一文件夹。
2. 双击 run_penta5_three_remain100.bat。
3. 脚本只处理 /root/penta5-runner/panel.html。

安全规则：
- 修改前自动备份 panel.html。
- 只接受已核验源 SHA256 或已完成目标 SHA256。
- 当前文件有其他变化时立即停止，不覆盖。
- 两个内联 script 逐个 node --check。
- 严格块、五项100配置、5000期、四组合索引均做唯一性检查。
- 运行四项语义测试：删900剩100、重复旧码只删一次、初始≤100原样、5000期扫完未到100保留真实剩余。
- 不重启 PM2；不修改 RDS、后端、接口、PM2 配置。
